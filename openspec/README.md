# OpenSpec records

This directory preserves historical OpenSpec proposals, designs, tasks, and
specifications. It is not a repository-local OpenSpec project, a dependency
for creating a game, or an automatic workflow trigger.

For new planning work, use the installed global OpenSpec skills in this order:
Explore, Propose, optional Update, then Apply. Do not install or generate local
skills. If a required global skill is unavailable, ask the user before using a
different process.

Read a record only when it is relevant to the requested work. Existing records
can document pending criteria, but they do not authorize implementation,
release, deployment, or a new planning workflow.
